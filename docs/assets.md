# Assets

## Models (`*.glb` at the repo root)

These are Sketchfab exports used by the scene. They are also listed in the editor's Assets tab as **built-in**:
they can be placed as model clips (`kind: "model"` layers) but not deleted.

| File | Used for | Notes |
|---|---|---|
| tuna_fish.glb | the tuna school | skinned; forward from the `Head_` → `UpperTail_` bones; baked + simplified in story mode |
| coral_fish.glb | reef fish school | **flip: true** |
| model_54a_-_caribbean_reef_shark.glb | 2 hunters | animated (`Action`), correct as-is |
| model_50a_-_hawksbill_sea_turtle.glb | 2 turtles | **yaw: π/2**; spec / gloss material (loader plugin) |
| blue_whale_-_textured.glb | animated whale | **flip: true** |
| game-ready_humpback_whale.glb | flexing whale | **flip: true** |
| coral_piece.glb | 160 instanced corals | |
| underwater_environment.glb | **not loaded** (56 MB) | photogrammetry reef, removed for load time |
| starfish__sarcophyton_….glb | **not loaded** (32 MB) | 800k tris — very heavy as a model clip |
| prins_jellyfish.glb | **not used** | replaced by the procedural jellies |

**Orientation rule:** if a creature swims backwards or sideways, fix it with `CONFIG` in `main.js` (`flip` / `yaw`)
and verify with the `?debug` arrows. Don't change the swim shaders. As model clips, use the layer's *Flip facing*
or a key's `rot`.

Keep paths relative (`./file.glb`, `assets/…`): the site lives under `/open-tuna/` on GitHub Pages.

## `assets/` (editor uploads)

- The editor's **Upload…**, drag-and-drop on the viewport, timeline or Assets tab, and *Replace file…* all copy
  files here (`POST /__editor/upload`). The name is slugged, and a clash gets a `-2` suffix.
- Allowed: images (png jpg webp gif svg avif), videos (mp4 webm mov m4v), `.html` pages (iframes), `.glb` / `.gltf`
  models, plus mp3 / ogg / wav / json.
- Committed with the story by the editor's git button. Large videos make the repo heavy: prefer compressed
  mp4 / webm.
- Delete through the Assets tab (it warns when a layer still uses the file).
